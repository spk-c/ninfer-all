# NInfer-all RTX 4090 v0.1.0 — CUDA 13.4 / SM89 for Windows

The first RTX 4090-focused Windows binary release of [SPK-C's NInfer-all fork](https://github.com/spk-c/ninfer-all-rtx4090).

**Target:** Windows 11 x64 · NVIDIA GeForce RTX 4090 (Ada Lovelace, SM89) · compatible NVIDIA driver · CUDA 13.4 **build** · portable NInfer runtime. **Model weights are not included.**

## What's included

- A native **SM89-only** CUDA build, matching the immutable `rtx4090-v0.1.0` source tag.
- Windows CLI, inference server, calibration tool, benchmarks and their necessary CUDA/runtime DLLs.
- Version/source metadata (`BUILD-INFO.json`), license notices, help files and SHA-256 manifests.
- A multi-volume 7-Zip archive, with all parts kept together for extraction.
- Fork-specific RTX 4090 build scripts, device calibration, GGUF profiling and experimental tuning controls in the tagged source code.

## Release qualification

The official release uploader builds from the **exact Git tag**, runs CTest, packages and validates the artifact through the existing Windows packager, checks the CUDA device images and clean-PATH launcher startup, verifies the archive and performs a real local RTX 4090 inference request with a user-supplied `.ninfer` model **before uploading or marking the release stable**. The release is only promoted to `Latest` once asset upload is checked.

If only source archives are available, the binary qualification/publishing step has **not** been completed, and the release must remain a prerelease.

## Install

1. Download **every** `.7z.NNN` part for the Windows SM89 package plus its `SHA256SUMS-*.txt` manifest.
2. Keep the parts in one directory. Check SHA-256 hashes against the manifest.
3. Use 7-Zip to extract the `.7z.001` part (it will read the others).
4. Read the bundled `README.md` and `BUILD-INFO.json`.
5. Start `ninfer-serve.exe` with your own compatible `.ninfer` weights. A compatible NVIDIA driver and the Visual C++ 2022 runtime are required.

## Examples and documentation

- [RTX 4090 build and benchmark guide](https://github.com/spk-c/ninfer-all-rtx4090/blob/master/docs/rtx4090.md)
- [Huihui model on Hugging Face](https://huggingface.co/SPK1337/Huihui-Qwen3.8-27B-Uncensored-GSQ-RCO-IQ3S-Vision-DFlash2-MTP-NInfer)
- [Huihui benchmark methodology](https://huggingface.co/SPK1337/Huihui-Qwen3.8-27B-Uncensored-GSQ-RCO-IQ3S-Vision-DFlash2-MTP-NInfer/blob/main/BENCHMARK-RTX4090.md)

In a real-world RTX 4090 / CUDA 13.4 DFlash2-5 serving workload (1,831 completed requests), the Huihui model recorded **146.6 tokens/s median** and **215.5 tokens/s 90th-percentile** per-request decode throughput. These logs are **not** a paired fork-vs-upstream speedup measurement or a performance promise for the packaged binaries. Experimental SFU, BF16x8 SiLU and GGUF IQ3_S T6-loop candidates remain **disabled** by default because stable whole-engine improvements were not established.
